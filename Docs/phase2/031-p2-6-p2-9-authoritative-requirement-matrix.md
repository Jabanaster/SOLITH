## REUSE/EXTEND/ADAPT/SUPERSEDE/NOT_RELEVANT classification summary (mission §2)

See the full audit in this stage's working notes; condensed:

- **REUSE**: `structure-model.ts`/`structure-interpretation.ts` (typed decode), `research/` subsystem (viewer/hex/pointer-analyzer/snapshot), `parseHexOffset`/`resolveMemoryFeatureAddress`/`SessionAddressCache`/`LIVE_ADDRESS_STRING` (address resolution+validation), `proposeWrite`/`confirmWrite`/`rollback`/`startFreeze` (write/freeze/revert engine), `trainer-hotkeys.ts` stack (hotkey model+registration+conflict detection).
- **EXTEND**: `MemoryRegion`/`MemoryModule` (need protection/state/module-path fields for a real memory map), `watch-list-bookmarks.ts`/`LiveWatchPanel.tsx` (need main-process/IPC backing + live refresh + provenance), `TrainerHotkeyAction` (need write/freeze/Advanced-Scan actions, not just overlay toggle), `FieldInterpretation.kind`/`ResearchDataType` (need one unified typed-value vocabulary).
- **ADAPT**: `PointerMapNodeStatus` vocabulary (adapt for watch/typed-value restart truth), `SnapshotWatchItem`/`SessionSnapshotManager.diff` (adapt if watchlist needs point-in-time diffing distinct from live polling).
- **SUPERSEDE**: none identified — no dead/wrong-direction subsystem found that P2-6-P2-9 work should replace.
- **NOT_RELEVANT**: none of the audited surfaces were irrelevant; `WritePolicyGate` is real but layered at `memory-manager.ts`, not `LiveMemorySession` — a design note for P2-9, not a NOT_RELEVANT surface.

No parallel truth model is created: typed views extend `FieldInterpretation`, watchlists extend `watch-list-bookmarks.ts`'s shape, memory map extends `MemoryRegion`/`MemoryModule`, hotkeys extend the existing `TrainerHotkeyAction` stack, and writes/freeze reuse the existing `LiveMemorySession` propose/confirm/rollback/freeze engine unchanged in its core contract.
