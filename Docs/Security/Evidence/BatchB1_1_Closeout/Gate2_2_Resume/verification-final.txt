`{proposalId, consentToken}`, but the renderer's exposed `liveMemoryFreezeStart` preload call
sends `{address, dataType, value, intervalMs}` and no `liveMemoryFreezePropose`/
`liveMemoryFreezeIssueConsent` preload methods exist — a real, pre-existing gap unrelated to
Gate 2.2 (see remaining-risks.md R-2.2-RESUME-001). Added one narrow test-only hook
(`__testStartFreezeForOwner`, `SOLITH_TEST_BUILD=1`-gated) that calls the exact same production
functions the real (currently broken) flow would call, so real freeze scenarios could still be
certified. See control-provenance.csv.
