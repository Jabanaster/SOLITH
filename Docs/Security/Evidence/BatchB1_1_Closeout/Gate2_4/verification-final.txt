R-2.3-001 RESOLVED. See packaged-real-flow-renderer-crash-matrix.csv.

## Phase 5 — Two-owner authorization isolation

The application's architecture has exactly one 'main'-type window; a true
two-independent-main-window test is not constructible without modifying
window-creation code (prohibited). The strongest genuine substitute — the
real Wisp overlay window, a second live trusted webContents — was used: it
could not request consent for, or start, the main window's proposal, while
the main window completed its own operation normally. R-2.3-002 RESOLVED
(narrowed, with the single-privileged-window architecture disclosed). See
packaged-owner-isolation-matrix.csv.

## Phase 6 — Main-window close and recreation

NOT APPLICABLE on this platform: electron/main.ts's window-all-closed
handler calls app.quit() whenever process.platform !== 'darwin', which is
always true on this Windows target. Full-restart state invalidation is
already proven by the existing Phase 4 lifecycle suite (rerun this cycle).
See packaged-window-recreation-matrix.csv.
